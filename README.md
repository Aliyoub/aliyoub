### Kubernetes — Récupération d'un Control Plane après expiration de certificats

Projet orienté **incident, diagnostic et récupération d'un environnement Kubernetes**.

Mise en situation autour de l'expiration de certificats du Control Plane, avec :

* analyse de l'état du cluster ;
* diagnostic des composants du Control Plane ;
* inspection de la PKI Kubernetes ;
* identification de la cause de l'incident ;
* procédures de récupération ;
* validation du retour à un état opérationnel ;
* documentation des actions correctives.

[Voir le projet](https://github.com/Aliyoub/kubernetes-control-plane-cert-expiry-recovery)
